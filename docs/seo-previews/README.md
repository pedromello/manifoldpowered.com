These 1200×630 PNGs were rendered by the real `/api/og` route with representative public Manifold content. They are review artifacts for the home, Outlet, and game variants; production previews remain dynamic and deterministic.

- `home-pt-BR.png`: institutional Manifold card.
- `outlet-strategos-void-pt-BR.png`: Strategos Void artwork with the Manifold lockup.
- `game-twisted-tower-pt-BR.png`: Twisted Tower key art with the Manifold lockup.

The Outlet and game routes fall back to branded gradients and content initials when remote artwork is absent, invalid, too large, slow, or outside the image host allowlist.
