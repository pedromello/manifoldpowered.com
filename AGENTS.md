# Repository instructions

## Confidential commercial integrations

- Treat the identity of any unannounced gift-card provider and the existence or status of related discussions as confidential.
- Do not put identifying names, domains, legal identifiers, logos, contract terms, or other clues in code, documentation, configuration, examples, tests, fixtures, screenshots, logs, branch names, commits, issues, pull requests, or comments.
- Use neutral names such as `gift_card_provider` and synthetic examples. Keep real counterparty details and documents in an approved private location outside this repository.
- Before publishing gift-card work, review the staged diff and any issue or pull request text for disclosures. If a public disclosure is found, stop publication and handle it privately; deleting a later commit does not remove earlier Git history.
- If a customer-facing or legal document requires identifying a provider, obtain explicit clearance for that disclosure before publishing it.
